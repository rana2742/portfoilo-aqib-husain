# Aqib Cloud Lab — Portfolio

A responsive static portfolio for Aqib Hussain, designed around an editorial engineering-notebook aesthetic: warm paper surfaces, blueprint details, bold typography and a cobalt-blue accent.

## Features
- Responsive layout and mobile navigation
- About, technical workbench, projects, journey and contact sections
- Interactive browser terminal with `help`, `about`, `skills`, `projects`, `achievements`, `contact`, `secret` and `clear`
- Visible hints that invite visitors to try the interactive feature
- No framework, package manager or build step required

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Deploy with AWS Amplify Hosting
1. Create a new GitHub repository, for example `aqib-cloud-lab`.
2. Push these files to the repository.
3. In AWS Amplify Console, choose **Create new app → Host web app → GitHub**.
4. Authorize GitHub, select the repository and `main` branch.
5. Review the build settings and deploy. This is a static site; `amplify.yml` uses the repository root as the published directory.
6. Open the generated Amplify URL and test the site on desktop and mobile.
