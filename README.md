## Run Locally

No installation or build process is required.

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

Alternatively, open the project in Visual Studio Code and run it using the Live Server extension.

## Deployment with AWS Amplify Hosting

1. Push the project to a GitHub repository.
2. Open the AWS Amplify Console.
3. Select **Create new app → Host web app**.
4. Connect your GitHub account and authorize repository access.
5. Select this repository and the `main` branch.
6. Review the build configuration in `amplify.yml`.
7. Deploy the application and open the generated hosting URL.

After deployment, test the website on desktop and mobile devices and verify the interactive terminal and navigation.
